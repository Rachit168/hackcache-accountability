# B05-A Resolution Audit Part 1

Backend checkpoint: read-only private audit sources and explicit bounded OpenRouter comparison. No migration or stored history change. Exact persisted original concerns, office-response ID/text/version/time and separate citizen dispute statements are loaded through the existing restricted `dispute_read` transaction. No evidence bytes or disputes are sent to the model; only concerns and the selected response. Provider transport is reused with its existing timeout and output limit. Additional controls permit two in-flight audits globally and four requests per identity per ten minutes, with bounded per-process bookkeeping.

Model output contains coverage enum, concern ID and exact quotations only. Every concern must appear once; unknown/duplicate IDs, fabricated quotes, missing concerns, unsupported extra properties and addressed/partial classifications without response quotations fail validation. Explanations are rendered from fixed labels plus the exact sources and quotations. Quotation matching is provenance, not semantic correctness or proof of resolution. Failure, missing configuration, oversized sources or invalid citations returns an honest unverified result with no prepared substitute. The UI permits explicit unsaved human review. Selected source references persist in the URL; generated interpretations are not persisted and reload is labelled accordingly.

Checks: `npm test` passed 98 tests / 18 files; `npm run build` passed typecheck and production build. `npx tsx qa/audit-connected.ts` passed four groups with real managed identities: owner/reviewer access; office/unrelated denial; distinct response versions; missing response and acknowledgement-only cases; actual OpenRouter validated coverage for one answered among three; vague closure plus prompt injection did not produce addressed coverage; separate attributed dispute; canonical ledger, complete source projection and retained B02 digest unchanged. Unit tests cover full/partial coverage, fabricated citations, substituted versions/IDs, omitted concerns, citizen disagreement, injection as data and unavailable provider. Controlled tests establish validation behavior, not live classifier accuracy; the connected runner separately checked live outputs.

Browser results and final observations will be added at publication. This is builder evidence, not independent acceptance. No truth, guilt, legality or actual-resolution determination is implemented.
